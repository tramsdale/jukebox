📋 CSV Format Requirements

Your CSV file should contain these columns (in any order):

  • Artist A side - Artist name for A-side (required)
  • Track A side - Track name for A-side (required)
  • Artist B side - Artist name for B-side
  • Track B side - Track name for B-side
  • In Jukebox - Status: "Y" for In Jukebox, "New" for New records
  • Jukebox ID - 3-digit jukebox number (e.g., 100, 101, 102...)
  • Genre - Music genre (optional)

Status Mapping:

  • "Y" or "`" → In Jukebox
  • "New" → New
  • Empty/Other → In Storage

Example CSV format:

Artist A side,Track A side,Artist B side,Track B side,In Jukebox,Jukebox ID The Beatles,Hey Jude,The Beatles,Revolution,Y,100 Madonna,Like a Virgin,Madonna,Material Girl,New, Johnny Cash,Ring of Fire,Johnny Cash,I Walk the Line,Y,101
Cancel

⚠️ Important Notes

  • Duplicate records (same Artist A-side + Track A-side) will be skipped
  • Records with missing Artist A-side or Track A-side will be skipped
  • Empty B-side fields will default to "Unknown"
  • Jukebox IDs will be formatted as 3-digit numbers (001, 002, etc.)
  • The import process will show how many records were imported vs skipped
