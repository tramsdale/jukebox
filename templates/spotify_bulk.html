Bulk Spotify Search

Search for Spotify links for multiple records at once. This process may take some time.

Note: This operation uses the Spotify Web API which has rate limits. Processing large batches may take time or fail if limits are exceeded.
Maximum 100 records per batch to avoid timeouts

How it works:

  • Searches for each track using Artist + Track Name on Spotify
  • Saves the first matching result URL and ID
  • Skips records that already have links (unless "Force refresh" is checked)
  • Shows progress and any errors encountered
